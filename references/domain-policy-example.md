# 도메인 정책 & 제약조건 (예시)

Agent C(도메인 분석)가 참조하는 프로덕트 도메인 정책입니다.
이 파일을 `domain-policy.md`로 복사한 뒤 자기 프로덕트에 맞게 작성하세요.

---

## 작성 가이드

도메인 정책 문서에는 아래 내용을 포함하세요:

### 1. 비즈니스 모델 구조
프로덕트의 핵심 비즈니스 로직, 수익 구조, 이해관계자 관계 등을 정리합니다.

```markdown
예시)
| 구분 | 내용 |
|------|------|
| 수익 모델 | 구독형 SaaS (월/연 결제) |
| 핵심 퍼널 | 가입 → 무료체험 → 유료전환 |
| 이해관계자 | 사용자(B2B 담당자), 관리자, 파트너 |
```

### 2. 도메인 제약 체크리스트
디자인 초안 시 반드시 확인해야 할 정책/규제 항목입니다.

```markdown
예시)
- [ ] 결제 관련 법적 고지사항 포함 여부
- [ ] 개인정보 수집 동의 UI 배치
- [ ] 연령 제한 확인 플로우
- [ ] 환불/취소 정책 접근성
- [ ] 약관 표시 의무사항
```

### 3. 도메인 용어 사전
사용자에게 노출되는 용어의 정의와 사용 기준입니다.

```markdown
예시)
| 용어 | 정의 | UI 표기 |
|------|------|---------|
| 워크스페이스 | 팀 단위 작업 공간 | "워크스페이스" |
| 멤버 | 워크스페이스 소속 사용자 | "팀원" |
```

### 4. 참고 링크
정책 원문, 내부 위키, 규제 가이드라인 등 외부 참조 문서를 연결합니다.

```markdown
예시)
- 서비스 이용약관: [링크]
- 개인정보처리방침: [링크]
- 내부 정책 위키: [링크]
```
