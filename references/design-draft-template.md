# {기능명} 디자인 초안

## 1. 컨텍스트 요약
- 에픽/디스커버리 핵심 목표 (1~2문장)
- 타겟 사용자 & 시나리오
- 성공 지표 (KPI)

## 2. 정보 구조 (IA)
- 화면 목록 & 계층
- 각 화면의 핵심 오브젝트

## 3. 유저 플로우
- Happy Path (메인 플로우)
- Edge Case (에러, 이탈, 예외)
- Mermaid 다이어그램

## 4. 와이어프레임 명세
- 화면별: 레이아웃 스켈레톤 (ASCII or 설명)
- 컴포넌트 목록 (디자인시스템 매핑)
- 상태별 UI (default / loading / empty / error / success)

## 5. UX 체크리스트
- 닐슨 휴리스틱 검증 결과

## 6. 비즈니스 검증
- 전환 퍼널 영향도
- 도메인 정책 제약사항
- 경쟁사 대비 차별점
