# UX 검증 체크리스트

디자인 초안의 Agent C(도메인 분석)가 UX 검증 시 사용하는 체크리스트.

## 닐슨 10가지 휴리스틱

- [ ] 시스템 상태 가시성: 로딩/완료/에러 상태가 노출되는가
- [ ] 실세계 일치: 사용자 언어를 사용하는가
- [ ] 사용자 제어: 되돌리기/취소가 가능한가
- [ ] 일관성: 동일 액션 = 동일 UI인가
- [ ] 에러 예방: 사전 방지 설계가 되어 있는가
- [ ] 인식 > 기억: 필요 정보가 화면에 노출되는가
- [ ] 유연성: 숙련자/초보자 모두 고려했는가
- [ ] 미니멀 디자인: 불필요 정보가 제거되었는가
- [ ] 에러 복구: 에러 메시지가 명확한가
- [ ] 도움말 접근성: 필요 시 도움말에 접근 가능한가

## UX 심리학 법칙

- [ ] Hick's Law: 선택지가 과도하게 많지 않은가
- [ ] Fitts's Law: 주요 CTA 버튼 크기/위치가 적절한가
- [ ] Miller's Law: 정보 덩어리가 7±2 이내인가
- [ ] Jakob's Law: 기존 패턴과 일치하는가
- [ ] Peak-End Rule: 핵심 순간과 마지막 경험이 좋은가
- [ ] Doherty Threshold: 응답속도 400ms 이내를 고려했는가
- [ ] Zeigarnik Effect: 미완성 태스크 유도를 활용했는가
